# orbyen-web
Página web da Orbyen.

Site estático de uma página, com escritório virtual no Espinheiro, plano anual, serviços incluídos e contato pelo botão “QUERO MAIS INFORMAÇÕES”.

## Arquivos

- `index.html`: conteúdo da página.
- `styles.css` e `fundos.css`: estilos e adaptação para computador e celular.
- `app.js`: código de interface preservado da versão aprovada.
- `assets/`: fotografia utilizada, logo, original da logo e ícone do site.

Não há instalação de dependências, compilação ou variáveis de ambiente. O diretório de publicação é a própria raiz do repositório, onde está `index.html`. Os caminhos dos arquivos são relativos para permitir servir a página tanto na raiz de um domínio quanto em um subdiretório.

## Estado da entrega

A versão foi preparada localmente em 15 de outubro de 2026. O aviso de prévia e a marcação HTML `noindex,nofollow` foram retirados desta cópia. As condições comerciais e o visual aprovado foram preservados.

Não foi realizado commit, push, ativação de hospedagem ou alteração de domínio. A publicação deve ser feita pelo proprietário após resolver a pendência da fotografia abaixo.

O GitHub Desktop pode ser usado para revisar, registrar e enviar as alterações deste repositório. O envio do código, por si só, não configura uma hospedagem. Nenhum serviço de publicação automática foi configurado nesta entrega.
